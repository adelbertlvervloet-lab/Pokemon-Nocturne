# Pokémon Nocturne

Unofficial, non-commercial transformative fan project.

Pokémon Nocturne is a multilingual novelistic-screenplay project
drawing selectively on Pokémon HeartGold/SoulSilver, FireRed/LeafGreen
and the musical and dramatic language of Castlevania: Nocturne.

## Languages

- Français — source text
- English — UK
- Italiano
- Deutsch — CH
- 日本語

## Contents

- `/episodes` — episode dossiers and PDFs
- `/apparatus` — notes, terminology and production references
- `/translations` — multilingual editions
- `/credits` — artwork, musical references and acknowledgements
